# Smart Campus Navigation System

## Project Overview

The Smart Campus Navigation System is a web application that helps students, faculty, and visitors locate departments, laboratories, classrooms, libraries, and other facilities within a college campus.

## Features

* Search departments and locations
* Interactive campus navigation
* Department-wise building information
* Responsive design
* Easy-to-use interface
* Real-time location guidance simulation

## Technologies Used

* React.js
* CSS3
* JavaScript (ES6)
* React Hooks
